## Reviewer account (both stores)

Store reviewers can't receive your sign-in emails, so VooSquare has a review sign-in:
1. VooSquare **Admin → Settings → General → App review account** (owner only).
2. Email: e.g. **review@voosquare.com**. Code: any 6 digits you choose (e.g. 246810). Turn it on and save.
   It only works for that one email, creates an ordinary free member called "App Review", and can never be a team account.
3. Give the same email and code to:
   - Google Play Console → App content → **App access** → "All or some functionality is restricted" → add the email and code as the login, with the note "Enter the email, tap Continue, then type this 6-digit code."
   - App Store Connect → the app version → **App Review Information → Sign-in required** → user name = the email, password = the code. In Notes add: "Enter the email, tap Continue, then type the code as the 6-digit sign-in code."
4. After both apps are approved you can turn it off (turn it back on before each new review).
